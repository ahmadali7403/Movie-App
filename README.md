# 🎬 Movie

A modern Netflix-style movie discovery web application built with React and TMDB API.

The application allows users to discover trending and top-rated movies, browse movies by genre, year and rating, search for movies, view detailed movie information, manage a personal movie list, and switch between profiles.

## ✨ Features

- 🎬 Netflix-style responsive UI
- 🔥 Trending movies
- ⭐ Top-rated movies
- 🎭 Browse movies by genre
- 📅 Filter movies by release year
- ⭐ Filter movies by minimum rating
- 🔎 Movie search with debounce
- 📖 Movie detail pages
- 👥 Cast information
- 🎞️ Similar movies
- 📋 My List functionality
- 💾 My List persistence using localStorage
- 👤 Profile selector
- 📱 Mobile-first responsive design
- 🖥️ Desktop and laptop optimized layout
- 👆 Touch-friendly horizontal movie rows on mobile
- ⚡ Skeleton loading states
- 🎨 Smooth animations with Framer Motion

## 🛠️ Tech Stack

- React
- Vite
- React Router DOM
- Tailwind CSS
- Axios
- Framer Motion
- Lucide React
- TMDB API
- localStorage
